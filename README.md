# Eye-Gaze Cursor Control Project

This project provides a suite of Python scripts for eye-gaze-based cursor control, utilizing webcam input and MediaPipe's face mesh capabilities. The workflow involves a calibration step to adapt to individual eye movements, followed by the actual cursor control, and a debug mode for fine-tuning and troubleshooting.

## Project Files:

* `calibrate.py`: Performs the initial calibration to map eye movements to screen coordinates.
* `cursor_control.py`: Uses the calibration data to control the mouse cursor with eye gaze and perform clicks via blinks.
* `debug_eye_tracker.py`: A debugging tool to visualize raw eye data, mapped cursor positions, and head pose.
* `requirements.txt`: Lists all Python dependencies for the project.

## `calibrate.py` (Calibration Script)

This script is crucial as it creates a personalized mapping between your eye movements (as detected by the webcam) and your screen coordinates. This mapping is saved to `calibration_data.pkl` and is essential for `cursor_control.py` to function accurately.

### How Calibration Works:

The `calibrate.py` script guides you through a series of on-screen calibration points. For each point, you are asked to look directly at a green circle. During this time, the script collects multiple samples of your eye's position relative to your face.

1.  **Eye Tracking**: The script utilizes MediaPipe's Face Mesh solution with `refine_landmarks=True` to detect detailed facial landmarks, including those for the irises.
2.  **Eye Center Calculation**: It calculates the average center of both irises (landmarks 474, 475, 476, 477 for the left iris and 469, 470, 471, 472 for the right iris). Averaging across both eyes provides a more stable and accurate gaze estimate.
3.  **Range Determination**: By collecting these eye center coordinates while you look at various known screen positions, the script determines the minimum and maximum X and Y coordinates your eyes can reach within the webcam's field of view that correspond to the extremes of your screen. This defines your personal eye movement range.
4.  **Data Storage**: The calculated `eye_x_min`, `eye_x_max`, `eye_y_min`, `eye_y_max`, along with your screen resolution, are saved to `calibration_data.pkl`.

### How to Use `calibrate.py`:

1.  **Install Dependencies:**
    Open your Git Bash or command prompt, navigate to the project directory, and install the required libraries using `requirements.txt`:
    ```bash
    pip install -r requirements.txt
    ```
    Alternatively, you can install them individually:
    ```bash
    pip install opencv-python mediapipe numpy pyautogui
    ```
2.  **Run the Script:**
    ```bash
    python calibrate.py
    ```
3.  **Follow On-Screen Instructions:**
    * A full-screen window will appear displaying a green circle at various points.
    * Look directly at the green circle each time it appears.
    * Keep your head as still as possible during the calibration process.
    * The process will go through multiple points to ensure a comprehensive calibration.
    * Press 'q' at any time to quit the calibration.
4.  **Completion:**
    Once finished, a `calibration_data.pkl` file will be created in your project directory. This file is essential for `cursor_control.py`.

## `cursor_control.py` (Cursor Control Script)

This is the main application that allows you to control your mouse cursor using your eye gaze and perform clicks by blinking.

### How it Works:

1.  **Loads Calibration Data**: It first loads the `calibration_data.pkl` file generated by `calibrate.py` to understand your unique eye-to-screen mapping.
2.  **Real-time Eye Tracking**: It continuously tracks your eye movements using the webcam and MediaPipe Face Mesh, obtaining your current eye center coordinates.
3.  **Mapping to Screen**: Using the loaded calibration ranges, it interpolates your current eye position to a corresponding screen coordinate (X, Y).
4.  **Mouse Movement**: The calculated screen coordinates are then used to move your system's mouse cursor using `pyautogui.moveTo()`. A `MOUSE_SMOOTHING_FACTOR` is applied to make the cursor movement less erratic.
5.  **Blink Detection for Click**:
    * The script calculates the Eye Aspect Ratio (EAR) for both eyes. EAR is a metric that indicates if an eye is open or closed.
    * It uses specific MediaPipe landmarks for the left eye (362, 382, 381, 263, 375, 374) and the right eye (33, 160, 158, 133, 153, 144) to compute the EAR.
    * When the average EAR of both eyes falls below a `BLINK_THRESHOLD` for a specified number of `BLINK_CONSEC_FRAMES`, a blink is detected.
    * Upon detecting a blink, `pyautogui.click()` is called to simulate a mouse click. A `CLICK_COOLDOWN_SECONDS` is implemented to prevent accidental multiple clicks.

### How to Use `cursor_control.py`:

1.  **Ensure Calibration is Done:** Make sure you have successfully run `calibrate.py` and have a `calibration_data.pkl` file.
2.  **Run the Script:**
    ```bash
    python cursor_control.py
    ```
3.  **Control and Click:**
    * Your webcam feed will appear, and the script will attempt to move your mouse cursor based on your eye gaze.
    * Blink to perform a left mouse click.
    * Press 'q' to quit the script.

## `debug_eye_tracker.py` (Debugging Script)

This script is a powerful tool for understanding and troubleshooting the eye-tracking system. It provides visual feedback and console output of various metrics.

### How it Works:

1.  **Loads Calibration Data**: Similar to `cursor_control.py`, it loads your calibration data.
2.  **Displays Target Points**: It presents a series of yellow target circles on the screen, similar to calibration.
3.  **Real-time Debug Info**: As you look at these points and move your eyes, it displays the following in the console (updated in real-time):
    * **Eye (norm)**: Your eye's current normalized X and Y coordinates (between 0 and 1).
    * **Mapped Mouse**: The X and Y coordinates on your screen where the cursor *would* be moved based on your eye gaze and the calibration.
    * **Actual Mouse**: The current X and Y coordinates of your actual mouse cursor.
    * **Head Pose (P/Y/R)**: Estimates your head's pitch (up/down tilt), yaw (left/right rotation), and roll (side-to-side tilt). This is calculated using `cv2.solvePnP` with a 3D model of facial points and their corresponding 2D webcam landmarks (nose tip, chin, outer eye corners, mouth corners). This helps in assessing head stability and its potential influence on gaze tracking.
4.  **Visual Feedback on Webcam Feed**: A green dot is drawn on the webcam feed indicating where the system is detecting your eye gaze.

### How to Use `debug_eye_tracker.py`:

1.  **Ensure Calibration is Done:** Make sure you have successfully run `calibrate.py`.
2.  **Run the Script:**
    ```bash
    python debug_eye_tracker.py
    ```
3.  **Observe and Analyze:**
    * A full-screen debug display will appear with yellow target circles.
    * Look at the yellow circles and try moving your eyes around the screen.
    * Observe the console output for real-time data. Pay close attention to how "Mapped Mouse" values change relative to your "Eye (norm)" values and the "Actual Mouse" position (if you move it manually).
    * Monitor the "Head Pose" values to see if your head movements are minimal, which is ideal for stable eye tracking.
    * Press 'q' to quit the script.

This debugging script is highly valuable for fine-tuning the `BLINK_THRESHOLD` and `MOUSE_SMOOTHING_FACTOR` in `cursor_control.py` by providing concrete data to analyze your eye movements and blink characteristics.
